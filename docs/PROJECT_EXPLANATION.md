## ⚙️ ૨. ડેટા અને સ્ટેટ મેનેજમેન્ટ કેવી રીતે કામ કરે છે?

### (A) `src/data/products.js` (ડેટા સ્ટોર)
- આ ફાઈલમાં ૧૨ જેટલી રિયાલિસ્ટિક ભારતીય ફેશન પ્રોડક્ટ્સ છે (જેમ કે લેહેંગા, શેરવાની, સાડી, કુર્તા).
- દરેક પ્રોડક્ટમાં `id`, `name`, `category`, `price`, `originalPrice`, `discount`, `rating`, `images[]`, `sizes[]`, `fabric`, `care` અને `description` જેવી વિગતો સ્ટોર કરેલી છે.
- ઉપરાંત `CATEGORIES`, `TESTIMONIALS` અને `PROMOS` (જેમ કે `VASTRIKA20`) નો ડેટા પણ અહીં છે.

### (B) `src/context/CartContext.jsx` (આખા પ્રોજેક્ટનું મગજ)
આ Context API આખા પ્રોજેક્ટમાં ડેટા શૅર કરે છે જેથી કોઈપણ પેજ પરથી કાર્ટ અપડેટ થઈ શકે:
1. **`cart`**: કાર્ટમાં કઈ આઈટમ્સ છે, કઈ સાઈઝ છે અને કેટલી ક્વોન્ટિટી છે.
2. **`wishlist`**: યુઝરે કઈ પ્રોડક્ટ્સ દિલ (❤️) પર ક્લિક કરીને સેવ કરી છે.
3. **`localStorage` Integration**: બ્રાઉઝર રિફ્રેશ થાય તો પણ કાર્ટ અને વિશલિસ્ટનો ડેટા ડિલીટ થતો નથી!
4. **Functions**:
   - `addToCart(product, size, qty)`: પ્રોડક્ટ કાર્ટમાં ઉમેરે છે. જો આઈટમ પહેલેથી હોય તો તેની ક્વોન્ટિટી વધારે છે (ડુપ્લિકેટ એન્ટ્રી થતી નથી).
   - `removeFromCart(id, size)`: આઈટમ દૂર કરે છે.
   - `updateQuantity(id, size, delta)`: `+` કે `-` બટન દબાવતાં સંખ્યા બદલે છે.
   - `applyPromo(code)`: `VASTRIKA20` નાખતાં ૨૦% ડિસ્કાઉન્ટ ગણે છે.
   - `openCart()` / `closeCart()`: કાર્ટ ડ્રોઅર ખોલે/બંધ કરે છે.
   - `openQuickView(product)`: ક્વિક વ્યુ પોપઅપ ખોલે છે.
   - `addToast(message)`: સ્ક્રીન પર નોટિફિકેશન મેસેજ બતાવે છે.

## 🖥️ ૩. પેજીસ (Pages) શું કામ કરે છે?

### 1. `Home.jsx` (`/`)
- આ વેબસાઇટનું મુખ્ય લેન્ડિંગ પેજ છે.
- **Hero Section**: મોટો બેનર ફોટો, સ્લોગન અને 'Shop Now' બટન.
- **Trust Bar**: 100% હેન્ડલૂમ, ફ્રી શિપિંગ અને 7-ડે એક્સચેન્જના બેજીસ.
- **Category Section**: પુરુષો, સ્ત્રીઓ, એથનિક, કેઝ્યુઅલ જેવી કેટેગરીઝના કાર્ડ્સ.
- **Featured / Bestseller Tabs**: ટ્રેન્ડિંગ પ્રોડક્ટ્સ બદલી શકાય તેવા ટેબ્સ.
- **Offer Banner**: ૨૦% ઑફનું કુપન કોડ કોપી બટન સાથેનું બેનર.
- **Testimonials & Lookbook**: ગ્રાહકોના રિવ્યૂ અને ઇન્સ્ટાગ્રામ ફોટોઝ.
- **Newsletter**: ન્યૂઝલેટર સબસ્ક્રિપ્શન.

### 2. `Shop.jsx` (`/shop`)
- આ શોપિંગ કેટલોગ પેજ છે.
- **Dynamic Filtering**:
  - **Category Filter**: Men, Women, Ethnic Wear વગેરે સિલેક્ટ કરી શકાય.
  - **Price Range Filter**: અંડર ₹3,000, ₹3,000 - ₹8,000 વગેરે.
  - **Size Filter**: S, M, L, XL, XXL મુજબ ફિલ્ટર.
  - **Live Search**: પ્રોડક્ટનું નામ ટાઈપ કરતાં જ તરત પરિણામ ફિલ્ટર થાય છે.
  - **Sorting**: Price Low to High, High to Low, Rating, Newest.

### 3. `ProductPage.jsx` (`/product/:id`)
- જ્યારે યુઝર કોઈપણ પ્રોડક્ટ પર ક્લિક કરે ત્યારે આ પેજ ખૂલે છે.
- આ પેજમાં પ્રોડક્ટના બધા ફોટાઓનું thumbnail gallery હોય છે.
- ગ્રાહક સાઈઝ પસંદ કરી શકે છે, ક્વોન્ટિટી પસંદ કરી શકે છે.
- **Add to Bag** અથવા **Buy Now** દબાવીને સીધું ચેકઆઉટ કરી શકે છે.
- નીચે **"You May Also Admire"** માં સંબંધિત બીજી પ્રોડક્ટ્સ સૂચવવામાં આવે છે.

### 4. `Cart.jsx` (`/cart`)
- યુઝરે પસંદ કરેલી બધી આઈટમ્સની યાદી બતાવે છે.
- ક્વોન્ટિટી વધારવા-ઘટાડવાના બટનો.
- **Free Shipping Bar**: ₹1,999 સુધી પહોંચવા કેટલા રૂપિયા ખૂટે છે તે પ્રોગ્રેસ બાર રૂપે બતાવે છે.
- **Coupon Code Box**: `VASTRIKA20` નાખીને Apply કરતાં તરત જ ડિસ્કાઉન્ટ બાદ થાય છે.
- **Order Summary**: Subtotal, Discount, Shipping, Total.
- **Proceed to Checkout** બટન.

### 5. `Wishlist.jsx` (`/wishlist`)
- યુઝરે ❤️ દબાવીને સેવ કરેલી બધી પ્રોડક્ટ્સ અહીં જોવા મળે છે.
- અહીંથી સીધું **"Move to Bag"** દબાવીને આઈટમ કાર્ટમાં લઈ જઈ શકાય છે.

### 6. `About.jsx` (`/about`)
- વાસ્ત્રિકા બ્રાન્ડની ફિલોસોફી અને વારસો.
- વારાણસી, ચંદેરી, લખનૌ અને જયપુરના વિવર ક્લસ્ટર્સની વિગતો.

### 7. `Contact.jsx` (`/contact`)
- ગ્રાહક સેવા સંપર્ક ફોર્મ (ઇન્કવાયરી સબમિટ કરવા માટે).
- શોરૂમનું સરનામું, ફોન નંબર અને સમય.
- વોટ્સએપ સપોર્ટ અને વારંવાર પૂછાતા પ્રશ્નો (FAQs Accordion).

## 🎨 ૫. Design System (`src/index.css`)
- **CSS Variables**: રંગો (`--maroon-primary: #6B1724`, `--gold-accent: #C5A059`, `--bg-main: #FDFBF7`) સરળતાથી બદલી શકાય તે માટે વેરિયેબલ્સમાં મુકેલા છે.
- **Responsiveness**: ડેસ્કટોપ માટે 4-column ગ્રીડ, ટેબલેટ માટે 2/3-column અને મોબાઈલ માટે 1/2-column તેમજ હેમબર્ગર મેનુ.
- **Fonts**:
  - `Cinzel` & `Cormorant Garamond` (રોયલ હેડિંગ્સ માટે)
  - `Plus Jakarta Sans` (ટેક્સ્ટ અને બટન્સ માટે)

## 🚀 ૬. પ્રોજેક્ટ કઈ રીતે રન કરવો?

```bash
# ૧. ડિરેક્ટરીમાં જાઓ
cd d:\Vastrika

```
