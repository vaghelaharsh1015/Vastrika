Complete Architecture Guide

Vastrika - કોડ અને પ્રોજેક્ટ ગાઈડ

આ સંપૂર્ણ વિગતવાર ગાઈડમાં Vastrika ઈ-કોમર્સ પ્રોજેક્ટની દરેક ફાઈલનો અસલી કોડ અને તે કોડ શું કામ કરે છે તેની સરળ ગુજરાતી સમજુતી આપેલી છે.

📁 ૧. પ્રોજેક્ટ ફોલ્ડર માળખું (Folder Structure)

આ પ્રોજેક્ટ Clean Architecture મુજબ ગોઠવાયેલો છે:

ફોલ્ડર / ફાઈલ શું કામ કરે છે?
src/data/ બધા કપડાં, ફોટા, પ્રાઈસ, કેટેગરીઝ અને કૂપનનો ડેટાબેઝ.
src/context/ કાર્ટ, વિશલિસ્ટ અને ગ્લોબલ સ્ટેટ મેનેજમેન્ટ (LocalStorage સાથે).
src/components/ નાના રીયુઝેબલ કમ્પોનન્ટ્સ (Navbar, ProductCard, Drawer, Modal, Toast).
src/pages/ મુખ્ય પેજીસ (Home, Shop, ProductPage, Cart, Wishlist, About, Contact).
src/index.css 100% Pure Vanilla CSS Design System (વેરિયેબલ્સ અને મીડિયા ક્વેરીઝ સાથે).

💻 ૨. src/main.jsx - પ્રોજેક્ટનું Entry Point

JSX 
import React from 'react';
import ReactDOM from 'react-dom/client';
import { BrowserRouter } from 'react-router-dom';
import { CartProvider } from './context/CartContext';
import App from './App';
import './index.css';

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <BrowserRouter>
      <CartProvider>
        <App />
      </CartProvider>
    </BrowserRouter>
  </React.StrictMode>
);

🔍 લાઈન-બાય-લાઈન સમજુતી:

  • ReactDOM.createRoot: HTML ના <div id="root"> માં React ને Load કરે છે.
  • <BrowserRouter>: React Router ને સક્રિય કરે છે જેથી પેજ રિલોડ થયા વગર URL બદલીને પેજ નેવિગેટ થઈ શકે.
  • <CartProvider>: આખા પ્રોજેક્ટને Wrap કરે છે જેથી Cart અને Wishlist નો ડેટા કોઈપણ પેજ પરથી એક્સેસ કરી શકાય.

🔍 લાઈન-બાય-લાઈન સમજુતી:

💻 ૪. src/context/CartContext.jsx - સ્ટેટ મેનેજમેન્ટ & લૉજિક

JSX 
// ૧. LocalStorage માંથી ડેટા લોડ કરવો
const [cart, setCart] = useState(() => {
  const saved = localStorage.getItem('vastrika_cart');
  return saved ? JSON.parse(saved) : [];
});

// ૨. કાર્ટમાં ફેરફાર થાય ત્યારે LocalStorage માં સેવ કરવું
useEffect(() => {
  localStorage.setItem('vastrika_cart', JSON.stringify(cart));
}, [cart]);

// ૩. Add to Cart લોજિક (ડુપ્લિકેટ ન બને તે માટે)
const addToCart = (product, size, qty = 1) => {
  const selectedSize = size || product.sizes[0];
  setCart((prev) => {
    const existing = prev.findIndex(
      (item) => item.product.id === product.id && item.selectedSize === selectedSize
    );
    if (existing > -1) {
      const updated = [...prev];
      updated[existing].quantity += qty;
      return updated;
    }
    return [...prev, { product, selectedSize, quantity: qty }];
  });
  setIsCartOpen(true); // કાર્ટ ડ્રોઅર ખોલો
};

// ૪. ડિસ્કાઉન્ટ અને ટોટલ ગણતરી
const cartSubtotal = cart.reduce((sum, item) => sum + item.product.price * item.quantity, 0);
const promoDiscount = appliedPromo ? Math.round((cartSubtotal * appliedPromo.discountPercent) / 100) : 0;
const shippingFee = cartSubtotal >= 1999 || cartSubtotal === 0 ? 0 : 199;
const cartTotal = Math.max(0, cartSubtotal - promoDiscount + shippingFee);

🔍 લાઈન-બાય-લાઈન સમજુતી:

  • localStorage: બ્રાઉઝર રિફ્રેશ કરવા છતાં કાર્ટ ખાલી થતું નથી.
  • existing > -1: જો એક જ આઈટમ ફરીથી ઉમેરાય તો નવી લાઈન બનાવવાને બદલે માત્ર ક્વોન્ટિટી વધારે છે.
  • shippingFee: જો ખરીદી ₹1,999 કે તેથી વધુ હોય તો શિપિંગ ₹0 (ફ્રી) ગણાય છે.

💻 ૫. src/components/ProductCard.jsx - પ્રોડક્ટ કાર્ડ

JSX 
const ProductCard = ({ product }) => {
  const { addToCart, toggleWishlist, isInWishlist, openQuickView } = useCart();
  const inWishlist = isInWishlist(product.id);

  return (
    <div className="product-card">
      {/* Wishlist Heart Toggle Button */}
      <button 
        className={`product-wishlist-btn ${inWishlist ? 'active' : ''}`}
        onClick={() => toggleWishlist(product)}
      >
        <Heart fill={inWishlist ? '#6B1724' : 'none'} color={inWishlist ? '#6B1724' : '#201715'} />
      </button>

      <Link to={`/product/${product.id}`}>
        <img src={product.images[0]} alt={product.name} />
      </Link>

      {/* Quick View */}
      <button className="product-quick-view" onClick={() => openQuickView(product)}>
        Quick View
      </button>

      <div className="product-info">
        <h3><Link to={`/product/${product.id}`}>{product.name}</Link></h3>
        <span className="current-price">₹{product.price.toLocaleString('en-IN')}</span>
        <button className="btn btn-primary btn-sm" onClick={() => addToCart(product)}>
          Add to Bag
        </button>
      </div>
    </div>
  );
};

🔍 લાઈન-બાય-લાઈન સમજુતી:

  • toggleWishlist: હાર્ટ પર ક્લિક કરતાં આઈટમ વિશલિસ્ટમાં ઉમેરાય/દૂર થાય છે.
  • openQuickView: પ્રોડક્ટ પેજ ખોલ્યા વગર જ સ્ક્રીન પર ક્વિક વ્યુ પૉપઅપ ખોલે છે.

💻 ૬. src/pages/Shop.jsx - ફિલ્ટર અને સર્ચ લૉજિક

JSX 
const filteredProducts = useMemo(() => {
  return PRODUCTS.filter((product) => {
    // ૧. Search Filter
    if (searchQuery.trim()) {
      const q = searchQuery.toLowerCase();
      if (!product.name.toLowerCase().includes(q)) return false;
    }
    // ૨. Category Filter
    if (selectedCategory !== 'All' && product.category !== selectedCategory) {
      return false;
    }
    // ૩. Price Filter
    if (product.price < selectedPriceRange.min || product.price > selectedPriceRange.max) {
      return false;
    }
    return true;
  }).sort((a, b) => {
    if (sortBy === 'price-low') return a.price - b.price;
    if (sortBy === 'price-high') return b.price - a.price;
    return 0;
  });
}, [selectedCategory, selectedPriceRange, sortBy, searchQuery]);

🔍 લાઈન-બાય-લાઈન સમજુતી:

  • useMemo: જ્યારે પણ યુઝર કેટેગરી કે પ્રાઈસ પસંદ કરે ત્યારે તરત જ રિસ્પોન્સિવ ફિલ્ટરિંગ કરે છે.
  • .sort(): ભાવ ઓછાથી વધુ કે વધુથી ઓછા મુજબ લાઈવ ક્રમ ગોઠવે છે.
