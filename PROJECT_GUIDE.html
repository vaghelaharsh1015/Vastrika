Vastrika - A to Z સંપૂર્ણ કોડ ગાઈડ

આ દસ્તાવેજમાં Vastrika ઇ-કોમર્સ વેબ એપ્લિકેશનની દરેક ફાઈલ (Context, Data, Components અને Pages) નો અસલી કોડ અને તેનું લાઈન-બાય-લાઈન ગુજરાતીમાં વિશ્લેષણ કરેલું છે.

src/main.jsx - પ્રોજેક્ટનું Entry Point

આ ફાઈલ બ્રાઉઝરના HTML ડોક્યુમેન્ટ સાથે React એપ્લિકેશનને જોડે છે.

JSX 
import React from 'react';
import ReactDOM from 'react-dom/client';
import { BrowserRouter } from 'react-router-dom';
import { CartProvider } from './context/CartContext';
import App from './App';
import './index.css';

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <BrowserRouter>
      <CartProvider>
        <App />
      </CartProvider>
    </BrowserRouter>
  </React.StrictMode>
);

🔍 લાઈન-બાય-લાઈન સમજુતી:

  • ReactDOM.createRoot: index.html માં આપેલા <div id="root"> માં React Component Tree બનાવે છે.
  • <BrowserRouter>: પેજ રીફ્રેશ થયા વિના URL પાથ બદલવા માટેનું Client-side Routing સક્ષમ કરે છે.
  • <CartProvider>: CartContext ને App ની ફરતે Wrap કરે છે જેથી કાર્ટ, વિશલિસ્ટ અને સર્ચ સ્ટેટ આખી એપ્લિકેશનમાં શૅર થાય.

src/App.jsx - પેજ Routing અને ગ્લોબલ Modals

આ ફાઈલમાં તમામ Routes (Pages) અને પોપઅપ મોડલ્સ ગોઠવાયેલા છે.

JSX 
const ScrollToTop = () => {
  const { pathname } = useLocation();
  useEffect(() => {
    window.scrollTo(0, 0); // પેજ બદલાય ત્યારે ઉપર સ્ક્રોલ થાય
  }, [pathname]);
  return null;
};

function App() {
  return (
    <div className="app-container">
      <ScrollToTop />
      <Navbar />

      <main style={{ flexGrow: 1 }}>
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/shop" element={<Shop />} />
          <Route path="/product/:id" element={<ProductPage />} />
          <Route path="/cart" element={<Cart />} />
          <Route path="/wishlist" element={<Wishlist />} />
          <Route path="/about" element={<About />} />
          <Route path="/contact" element={<Contact />} />
        </Routes>
      </main>

      <Footer />

      {/* Global Modals & Drawers */}
      <CartDrawer />
      <SearchBar />
      <QuickViewModal />
      <CheckoutModal />
      <Toast />
    </div>
  );
}

🔍 લાઈન-બાય-લાઈન સમજુતી:

  • ScrollToTop: useLocation() હૂક વડે જ્યારે પણ યુઝર પેજ બદલે ત્યારે પેજ ટોપ પર સ્ક્રોલ કરી આપે છે.
  • <Routes>: URL પાથ મુજબ યોગ્ય પેજ Component રેન્ડર કરે છે.
  • ગ્લોબલ કમ્પોનન્ટ્સ: CartDrawer, SearchBar, QuickViewModal, CheckoutModal અને Toast ને અહીં મૂકવાથી તે એપમાં ગમે ત્યાંથી ટ્રિગર થઈ શકે છે.

src/context/CartContext.jsx - સ્ટેટ મેનેજમેન્ટ & બિઝનેસ લૉજિક

પ્રોજેક્ટનું આખું બિઝનેસ લૉજિક (Cart, Wishlist, Coupons, Shipping) આ ફાઈલમાં છે.

JSX 
// ૧. LocalStorage માંથી Initial Cart Load
const [cart, setCart] = useState(() => {
  const saved = localStorage.getItem('vastrika_cart');
  return saved ? JSON.parse(saved) : [];
});

// ૨. Cart Update થાય ત્યારે LocalStorage માં Save
useEffect(() => {
  localStorage.setItem('vastrika_cart', JSON.stringify(cart));
}, [cart]);

// ૩. Add to Cart (સાથે સાઇઝ અને ક્વોન્ટિટી હેન્ડલિંગ)
const addToCart = (product, size = null, quantity = 1) => {
  const selectedSize = size || product.sizes[0] || 'Free Size';
  const qty = Math.max(1, parseInt(quantity, 10) || 1);

  setCart((prev) => {
    const existingIndex = prev.findIndex(
      (item) => item.product.id === product.id && item.selectedSize === selectedSize
    );
    if (existingIndex > -1) {
      // Duplicate અટકાવી ફક્ત સંખ્યા વધારે છે
      const updated = [...prev];
      updated[existingIndex].quantity += qty;
      return updated;
    }
    return [...prev, { product, selectedSize, quantity: qty }];
  });

  addToast(`Added "${product.name.slice(0, 24)}..." to your bag!`);
  setIsCartOpen(true); // સ્લાઈડિંગ કાર્ટ ખોલે છે
};

// ૪. Total, Discount & Free Shipping ગણતરી
const cartSubtotal = cart.reduce((sum, item) => sum + item.product.price * item.quantity, 0);
const promoDiscount = appliedPromo ? Math.round((cartSubtotal * appliedPromo.discountPercent) / 100) : 0;
const shippingFee = cartSubtotal >= 1999 || cartSubtotal === 0 ? 0 : 199;
const cartTotal = Math.max(0, cartSubtotal - promoDiscount + shippingFee);

🔍 લાઈન-બાય-લાઈન સમજુતી:

  • localStorage: પેજ રિફ્રેશ થાય તો પણ ગ્રાહકની પસંદ કરેલી આઈટમ્સ સુરક્ષિત રહે છે.
  • existingIndex > -1: એક જ પ્રોડક્ટ અને સાઈઝ ફરી એડ કરતાં કાર્ટમાં ડુપ્લિકેટ લાઈન નથી બનતી પણ ક્વોન્ટિટી વધી જાય છે.
  • shippingFee: ₹1,999 થી વધુના ઓર્ડર પર આપમેળે શિપિંગ ચાર્જ ₹0 (FREE) થઈ જાય છે.

// CartDrawer.jsx
const CartDrawer = () => {
  const { cart, isCartOpen, closeCart, cartCount, cartSubtotal, openCheckout } = useCart();
  const freeShippingThreshold = 1999;
  const progress = Math.min(100, Math.round((cartSubtotal / freeShippingThreshold) * 100));

  return (
    <div className={`cart-drawer ${isCartOpen ? 'open' : ''}`}>
      <div className="drawer-header">
        <h3>Shopping Bag ({cartCount})</h3>
        <button onClick={closeCart}><X /></button>
      </div>
      {/* Free shipping bar */}
      <div className="progress-bar" style={{ width: `${progress}%` }} />
      {/* Cart Items */}
      {cart.map((item, idx) => <CartItem key={idx} item={item} />)}
      <button className="btn btn-primary" onClick={openCheckout}>Checkout</button>
    </div>

const filteredProducts = useMemo(() => {
  return PRODUCTS.filter((product) => {
    if (searchQuery && !product.name.toLowerCase().includes(searchQuery.toLowerCase())) return false;
    if (selectedCategory !== 'All' && product.category !== selectedCategory) return false;
    if (product.price < selectedPriceRange.min || product.price > selectedPriceRange.max) return false;
    if (selectedSize !== 'All' && !product.sizes.includes(selectedSize)) return false;
    return true;
  }).sort((a, b) => {
    if (sortBy === 'price-low') return a.price - b.price;
    if (sortBy === 'price-high') return b.price - a.price;
    return 0;
  });
}, [selectedCategory, selectedPriceRange, selectedSize, sortBy, searchQuery]);
